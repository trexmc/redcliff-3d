# 赤壁之戰 ‧ 3D 戰史特別節目

> **線上展示：https://trexmc.github.io/redcliff-3d/**
> 單一 HTML 檔（`index.html`）、零建置、Three.js CDN 載入，推上 GitHub Pages 即可運行。

以電視特別節目的 3D 運鏡方式呈現赤壁之戰（西元 208 年）：地形、地名、艦隊、軍旗、計策、天氣與時間軸全部即時渲染，可自動播放（歷史節目模式）也可自由操作鏡頭（遊戲模式）。

---

| 類別 | 內容 |

| 3D 場景 | 長江、南岸赤壁紅崖、北岸烏林丘陵、動態水面 |

| 時間軸 | 10 幕劇情，可拖曳、點刻度跳轉、0.5×–4× 變速、自動播放 |
| 計策特效 | 連環計、詐降計、借東風、火燒連環船、義釋華容──金色大字發動動畫 |
| 戰鬥特效 | 火焰／濃煙粒子、火箭、爆炸火花、船隻燃燒傾斜下沉、鐵索連舟 |

## 程式結構（index.html 內的區段）

依檔案內 `/* ==== */` 註解區塊順序：

1. **CSS**：HUD 面板樣式 + `@media (max-width:768px)` 行動版
2. **HTML**：標題列、劇情卡、計策特效層、天氣、戰力面板、戰報、詞句字幕、控制列
3. **基本場景**：renderer / scene / camera / OrbitControls / 光源（`IS_MOBILE` 時關陰影）
4. **地形**：`terrainH(x,z)` 高度函式（江道、赤壁崖、烏林丘）＋頂點色
5. **文字標籤**：`textSprite()` canvas → Sprite；地名標示
6. **軍旗**：`flagTexture(字, 色)`、`makeFlag(side)`
7. **船艦**：`makeShip(side, big)`、`makeChains()` 鐵索
8. **陸軍**：`makeArmy(side, rows, cols)` InstancedMesh
9. **粒子**：`makeParticles / spawn / stepParticles`（火、煙、箭、風、火花）
10. **`phases[]` 時間軸資料** ← 改劇情主要動這裡
11. **`applyTime(t)`**：插值套用位置/狀態/天氣/HUD，進新幕時觸發戰報+計策+`onPhaseEnter`
12. **旁白/配樂/字幕**：`narrate()`、`scheduleMusic()`（五聲音階古箏，無鼓）、`LYRICS[]`、`MUSIC_INTENSITY[]`
13. **電影運鏡**：`cineCamera()`；pointerdown 即切自由鏡頭
14. **控制列**：播放/暫停、速度、重播、戰報(手機)、旁白、音樂開關
15. **主迴圈**：水波、旗幟、船隻浮沉燃燒、粒子發射、旁白閘門（唸完才換幕）

### 修改劇情的方法

每一幕是 `phases[]` 裡一個物件：

```js
{ t:6, name:'火燒赤壁', date:'甲子日 夜半',
  desc:'旁白會唸這段……',           // 劇情卡 + 旁白文字
  log:'戰報列 <b>HTML</b>',
  strat:{name:'火 燒 連 環 船', who:'黃蓋 ‧ 周瑜'},  // 計策特效（可省略）
  weather:['🔥','夜 ‧ 東南風助火勢'],
  night:true, wind:true, chained:true, burning:.6, arrows:true,  // 特效開關
  cao:{f:P(-90,-38,0), a:P(-120,-115)},   // f=艦隊 a=陸軍 (x,z,旋轉)
  sun:{f:P(20,25,Math.PI)}, liu:{…}, fire:P(-70,-25,Math.PI),
  str:{cao:.55,sun:.96,liu:1},            // 戰力比例（驅動 HUD 條）
  states:['水寨陷入火海！','總攻擊！','向北岸推進'],
  cam:{pos:[-30,90,170], tgt:[-75,8,-30]} }  // 該幕電影機位
```

相鄰兩幕之間自動以緩動函式插值（位置、戰力、晝夜、燃燒程度）。
同步要改的還有：`LYRICS[]`（每幕詞句）、`MUSIC_INTENSITY[]`（每幕音樂張力 0–1）。

## 本機開發與部署

```powershell
# 本機預覽（任何靜態伺服器皆可）
python -m http.server 8741 --directory redcliff-3d
# → http://localhost:8741

# 部署：推上 main 即自動發佈（GitHub Pages legacy build，約 20–60 秒生效）
git add index.html; git commit -m "..."; git push
```

- Repo：`trexmc/redcliff-3d`（public）
- Pages 設定：`main` 分支根目錄（已透過 `gh api repos/{repo}/pages -X POST` 啟用）
- 瀏覽器音訊政策：旁白/音樂需使用者點擊頁面一次後才會發聲

## 開發紀錄（重要決策）

- **鼓聲全移除**：戰鼓的噪音成分＋急促連擊聽起來像馬蹄聲，使用者反映後先軟化、最終整段移除，只留古箏撥弦
- **旁白閘門**：每幕原固定 9 秒，但長旁白會被切斷；現在自動播放會停在幕尾等 `speechSynthesis` 唸完才進下一幕
- **行動版**：戰力面板改底部橫條、戰報改浮層按鈕開關、手機關陰影並降 pixelRatio
